## 1.1 Auditable, reproducible AI-assisted development _(NEED001)_ {#NEED001}

Everyone who reads, reviews or reuses this repository needs to see how LLM coding agents shaped it: which prompts were given, what the agent answered and did, with which model and when - kept next to the code, in the same history, and readable without an LLM.

*Child links: REQ001, REQ003*

## 1.2 Traceable engineering _(NEED002)_ {#NEED002}

Maintainers and reviewers need to trace every intended behaviour of the software from the stakeholder need, through a testable requirement and its design, to the automated test that proves it - so that code written quickly with an LLM is still specified, reviewable and verifiable.

*Child links: REQ002, REQ003*

## 2.1 Sourced evidence base for the IB conversion-table op-ed _(NEED003)_ {#NEED003}

The author needs a reproducible, fully sourced evidence base - reports and data - on grade inflation in Norway and other Western countries, the stability of International Baccalaureate (IB) Diploma results, PISA trends, and the Norwegian IB conversion table, so that a data-driven op-ed can be written and every number in it can be traced to a primary source.

*Child links: REQ004, REQ005*
