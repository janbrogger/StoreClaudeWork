# Sources

Evidence base for a data-driven op-ed on the Norwegian conversion table for
International Baccalaureate (IB) Diploma points. Thesis under test: Norwegian
(and Western) school grades have inflated while the exam-based IB Diploma has
stayed psychometrically stable, and PISA scores have fallen.

Conventions

- Reports are Markdown; data are CSV (UTF-8, comma-separated, header row, one
  observation per row, with `source_url` and `note` columns).
- Every report ends with a **Sources** section (URL, title, publisher, date,
  how accessed). Numbers taken from search snippets rather than the primary
  document are marked as such; nothing is fabricated.
- Each folder has a `TO-FETCH.md` listing primary documents and API queries
  still to be retrieved from an unrestricted machine.

| Folder | Content |
|---|---|
| `media-and-policy/` | Norwegian narrative: history of the conversion table, government, Storting, NIBS, media coverage |
| `conversion-table/` | The 2022, 2025 and 2026 tables themselves, their method, foreign conversion tables |
| `norway-grades/` | Norwegian grade statistics over time (Udir, SSB, Samordna opptak) and grade-inflation research |
| `pisa/` | PISA time series for Norway and comparison countries |
| `ib-statistics/` | IB Diploma statistical bulletins: May-session time series |
| `ib-assessment-design/` | Psychometric design of IB assessment, ACER/ISA links, predictive validity |
| `grade-inflation-international/` | Grade inflation in other Western countries |
| `papers/` | Academic papers supplied by the author |
